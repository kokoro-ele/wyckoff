Composite Man

Treat the tape as one operator — the Composite Man — accumulating in panic and distributing into euphoria. Springs and UTADs are fake breaks meant to flush the other side. The job is to recover intent from volume and spread, not to list indicators.

Accumulation → Markup → Distribution → Markdown

A trading range inside accumulation or distribution is split into phases A–E. Markup / markdown live mostly in phase E, after price has left the range.

Schematics · events on the tape

Schematic K-lines (not real prices). Red = up bar, teal = down bar (A-share convention). Event tags use the same bias colors as wyckoffEventTag: bullish below the low, bearish above the high, neutral on the relevant wick. The dashed box is the trading range; top rail = creek, bottom rail = ice / support.

Accumulation

Accumulation · Phase A stops the decline (PS/SC/AR/ST) → B builds cause → C Spring → D SOS/LPS → E markup

Distribution

Distribution · Phase A tops the advance (PSY/BC/AR/ST) → B / UT → C UTAD → D SOW/LPSY → E markdown

Three laws

Supply and demand

Demand > supply → price rises; the reverse falls. Read the balance from spread × volume.

Cause and effect

Time and amplitude in the range are the cause; the move after the break is the effect. Larger cause → larger effect. (P&F counts are not implemented.)

Effort vs result

Volume is effort; price change is result. Divergence (climax volume + a narrow doji) often precedes a turn. The engine flags no_result / no_effort.

Phases A–E

Defined in WYCKOFF_PHASES. Chart zones use these letters. Range first, then events — a Spring with no range is meaningless.

A · Stopping the prior trend — Exhaustion of selling (or buying). PS/SC/AR/ST or PSY/BC/AR/ST set the first range bounds.
B · Building the cause — Composite Man accumulates or distributes inside the box. Longest phase: many secondary tests, chop.
C · The test — Last deceptive break: Spring / Shakeout (accumulation) or UTAD (distribution).
D · Trend revealed — Demand (or supply) takes over. SOS/LPS or SOW/LPSY. Highest-odds campaign entries.
E · Out of the range — Markup or markdown underway; the effect starts to pay.

Accumulation vs distribution: a range after a long decline may be accumulation; after a long advance, distribution. The feature summary’s “prior trend” is a hint, not a verdict.

How the workbench uses this

OHLCV → packages/wyckoff (swings, range, VSA) → MarketFeatures → Agent names events → overlays

The model must not invent codes. draw_annotations only accepts WYCKOFF_EVENT_CODES. The engine finds ranges and VSA; naming is the Agent’s job.

  • event → wyckoffEventTag (SC / Spring / UTAD, …)
  • zone → wyckoffZone (range + optional phase A–E)
  • level → horizontal (creek, ice, spring low)
  • trendline → creek / ice / demand / supply line

Not in v1: point-and-figure cause-and-effect counts, and automatic phase classification.
